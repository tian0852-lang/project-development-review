# B21 — Page resource inventory and confirmation

Core version: 2.2.1.

## Verification scope and environment prerequisites

Behavior scenario in an authorized disposable review workspace. Use one selected Figma or MasterGo source and a controlled page containing at least one icon and one image. Record client/version/model and the complete response transcript.

## Input materials

The selected source returns page nodes, an icon, an image and partial readability for original dimensions. The user has not yet confirmed the page or resource list.

## Expected behavior

Render PAGE & RESOURCE CHECKPOINT directly in chat. Show page count, every page ID, Resource IDs grouped by page, source node/layer IDs, icon/image dimensions (original/design/export/runtime), scale, format, location, rights/accessibility, save root and unresolved questions. Keep unreadable dimensions as Open questions. Wait for explicit confirmation or correction of the displayed page/resource version.

## Must not happen

Do not only list resources in a file, infer original dimensions from a screenshot, save files before confirmation, create a technical assessment card, or treat a filename as proof of identity.

## Pass criteria

The displayed panel contains the complete page/resource candidate and no resource is Approved or Saved before the user affirms that version.
