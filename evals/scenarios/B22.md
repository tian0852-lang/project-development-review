# B22 — Existing-project resource delta

Core version: 2.2.1.

## Verification scope and environment prerequisites

Behavior scenario for change or mixed mode in a disposable review workspace. Provide a previous review resource inventory when available and a current selected-source inventory.

## Input materials

The previous inventory contains ICON-001 and IMG-001. The current source keeps ICON-001, changes IMG-001 dimensions, adds IMG-002 and no longer exposes an old decorative image.

## Expected behavior

Load the previous inventory, compare stable IDs/source nodes/content and show Unchanged, Modified, New, Removed, Moved or Unknown rows. Scan shared components, design tokens, page usage and acceptance impact. Reconfirm only affected scope; if no historical inventory exists, state that limitation instead of fabricating one.

## Must not happen

Do not classify a delta from filename alone, treat an existing file as product approval, mark a cross-page dimension change Local without a scan, or invalidate unaffected approvals without evidence.

## Pass criteria

The transcript and change artifact contain the complete resource delta, evidence limits, impact classification and affected confirmation scope.
