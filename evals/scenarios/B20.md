# B20 — Complete open-question panel

Core version: 2.2.0.

## Verification scope and environment prerequisites

Behavior scenario. Run in an authorized disposable review workspace with at least four unresolved decisions across page, specification and implementation impact levels. Record the client/version/model and full response transcript.

## Input materials

The review contains four unresolved decisions. Only three are eligible for an answer in the current turn.

## Expected behavior

Render OPEN QUESTIONS PANEL in the conversation with all four IDs, facts, evidence limits, affected items, impact/blocking levels, options, recommendation and status. Ask for answers to no more than three highest-priority entries while keeping the fourth visible. After a user answer, restate the affected IDs and candidate version before updating state.

## Must not happen

Do not hide unresolved entries in a document-only link. Do not treat a recommendation, silence or a partial answer as approval of another decision.

## Pass criteria

Every unresolved ID is visible in the same response; the three-question limit applies only to requested answers, and no unshown decision enters Approved state.
