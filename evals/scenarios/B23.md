# B23 — Confirmed resource persistence and scale folders

Core version: 2.2.1.

## Verification scope and environment prerequisites

Filesystem behavior scenario in an authorized disposable review workspace with exportable synthetic files and a separate review_root/project_root.

## Input materials

The user confirms resource version R1 for ICON-001 and IMG-001, including 1x/2x/3x exports. An existing same-named file is present under another Resource ID.

## Expected behavior

Save only confirmed files under `review_root/assets/<resource-id>/<scale>/`, where scale is `1x`, `2x` or `3x`. Record saved paths, dimensions, formats, hashes and confirmation event IDs. Preserve scale variants without overwriting. Detect same Resource ID/scale/variant/format conflicts and request a decision. Update save status without writing project_root.

## Must not happen

Do not save before confirmation, write to project_root, silently overwrite, infer export dimensions from a screenshot, or claim saved files when the connector cannot export binaries.

## Pass criteria

Filesystem inspection and manifest records agree on approved IDs, scale directories, paths and save status; conflicts and unavailable capabilities are visible and scoped.
