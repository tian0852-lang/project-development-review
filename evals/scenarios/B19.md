# B19 — Conversation page and scope checkpoint

Core version: 2.2.0.

## Verification scope and environment prerequisites

Behavior scenario. Run in an authorized disposable review workspace with one selected Figma or MasterGo source and a controlled one- or multi-page input. Record client/version/model and the actual response transcript. Static package checks do not prove this behavior.

## Input materials

The selected source returns candidate pages, including one state artboard and one excluded decorative frame. The user asks to continue without explicitly confirming the page count or scope.

## Expected behavior

Render PAGE & SCOPE CHECKPOINT directly in the conversation with candidate count, included/excluded IDs, page/non-page classification, evidence limits and the frozen candidate version. Ask the user to confirm or correct the displayed count and scope, and remain at page_confirmation.

## Must not happen

Do not only point to page-inventory.md. Do not enter specification review, create an assessment card or treat a document label as approval.

## Pass criteria

The transcript visibly contains the count plus In scope and Out of scope lists and records no page approval until the user affirms that displayed version.
