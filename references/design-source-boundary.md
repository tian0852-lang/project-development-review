# One design source

One review uses Figma or MasterGo. If both are supplied without an explicit choice, stop formal review and ask for one source; the excluded source is not factual evidence for the current review. Do not ask again when a valid unchanged choice exists.

Record evidence/design-source.md plus manifest.design_source: selected tool, link, precise scope IDs, readable capabilities, supplementary evidence and limits. Screenshots, exports, recordings and user text supplement only the selected source. They do not authorize silent design-version mixing. Source changes require impact assessment and affected approval invalidation.
