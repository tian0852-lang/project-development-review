# Prototype and annotation reading

When exposed, record source page/node, trigger, action, destination, transition, evidence ID/location, readable range and limitations.
Figma NAVIGATE/SWAP supply navigation drafts; OVERLAY supplies overlay/dialog drafts. These are intent and acceptance evidence, not complete runnable logic. Missing parameters, return state, button outcomes, close/back/overlay behavior and state effects remain decisions.
Annotation text/category/properties never prove author identity; request actual attribution if needed.

For MasterGo, use only fields actually returned. If only static structure is available, request marked screenshots, recordings, text or explicit page relationships as user_provided evidence. Do not infer a resend action from a resend label. Never reinterpret a user's business number as a likely typo; open a decision with options.
