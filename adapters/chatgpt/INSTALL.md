# ChatGPT adapter — 2.2.0

## Installation and invocation

For an eligible workspace, open Plugins → Skills → Create → Upload from your computer and provide the complete package in the accepted upload form. Attach/select the installed Skill explicitly, or request it by name; automatic selection is possible, not guaranteed. Availability remains account and workspace dependent. [Official Skills guide](https://help.openai.com/en/articles/20001066-skills-in-chatgpt)

Record the uploaded version and readable SKILL.md resource/location. Keep [rules.md](rules.md) in the available project instructions; if no persistent instructions are available, include it at the start of each conversation. Use [invocation.md](invocation.md) for the staged start. Do not treat a local desktop path as readable by a cloud conversation.

## Private distribution and fallback

A skill-only plugin is an optional distribution container, not supplied or installed by this upgrade. Follow the current private/local workflow supported by your workspace; a universal local plugin uploader is not asserted. No public listing is authorized. [Official plugin overview](https://help.openai.com/en/articles/20001256-plugins-in-chatgpt-and-codex)

Without Skill access, attach the complete rules/templates and project evidence and use [fallback-prompt.md](fallback-prompt.md). Missing core materials restrict progress to intake/page drafts. No filesystem access means text-only delivery, not saved files or validated hashes.
